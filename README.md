# WORLD // LIVE

A JARVIS-inspired world intelligence interface built around public data APIs.

## Initial stack
- React + TypeScript + Vite
- Three.js via React Three Fiber
- FastAPI backend (next phase)
- Public APIs: USGS earthquakes and Open-Meteo weather

## Current state
Frontend foundation with a holographic globe-style core, live status shell, command input, and event visualization scaffold.

## Run
```bash
cd frontend
npm install
npm run dev
```
